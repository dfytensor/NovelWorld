# NovelWorld · 小说涌现系统

> **方法论驱动 · 情绪价值量化 · 多智能体涌现 · 自动管线生产**
> 一套完整的中文小说创作系统：从设计卡到 60,000 字完本，全程可检测、可回溯、可复现。

## 系统架构

```
方法层: skill/ (30文件) — 五阶流程+九道闸+四账本+八大表达体系
引擎层: JEV 多智能体 — 角色世界+词签判定器+涌现剧场(可视化)
自动层: pipeline/ — 五阶orchestrator+三维护器+对账器+39签检测器
标尺层: 真书库19万本对标 + 番茄榜单校准
```

## 核心能力

| 能力 | 说明 |
|---|---|
| 五阶创作管线 | 设计→大纲→细纲→创作→润色，每阶段有 Gates |
| 情绪价值检测 | 39 签三层词签（情节/角色/情绪），千字密度量化 |
| 四账本实时维护 | 伏笔双账(F编号制)＋角色情绪弧＋道具流转＋章级快照 |
| 九道 Gates | 违例即停——细纲/账本/配额/连续性/字数/机械全覆盖 |
| 真书库对标 | 19 万本真书采样，均值 29/39，头部 38.7/39 |
| 八大表达体系 | S口语/B行为/M微表情/T全类别/G怼人/N命名/W战斗/X修仙 |

## 快速开始

```powershell
# 1. 检测器
.\skill\scripts\scan-emotion.ps1 -Path <小说文件或目录>

# 2. 自动管线（需配置 LLM API）
.\涌现系统\pipeline\novel_pipeline.ps1 -BookDir <输出目录> -Tags "标签组合"

# 3. 伏笔对账器
.\涌现系统\pipeline\伏笔钩子对账器.ps1 -BookDir <书目录>
```
