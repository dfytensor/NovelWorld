# 生产线 SOP · 上榜保障清单（单页操作卡）
# 用途：每开一本书，从设计到完结，照此卡逐项执行。全部打勾 = 具备上榜资质。

---

## A. 设计期（开书前·未齐不开写）

- [ ] 五层标签勾选≥：主分类1 情节2-3 角色≥2 情绪3 背景1
- [ ] 书名过 N 系列六式之一 + 三秒测试（数得出≥2标签）
- [ ] 人物卡：主角+配角 X 六面体全填；每人一句“性格指纹”（微表情习惯）
- [ ] 选题卡写明本书记交付的 3 种情绪（签位目标）
- [ ] 世界观背景检查清单过一遍

## B. 大纲期

- [ ] 每卷 3-5 发展节点；时间账（一句话/卷）
- [ ] 章节标题：四钩检验 + 全书钩型轮换表（无同型连用）
- [ ] 卷情绪配色表：每卷标主色+辅色（对齐3种交付情绪）

## C. 细纲期（每章动笔前）

- [ ] 七项齐：伏笔(埋/收) 出场人物 钩子(标型) 概述 段子/梗(过背景兼容闸) 情绪目标(≥4签) 三栏表(双闸)
- [ ] 持续诊断环重跑：钩子链 / 伏笔账 / 爱恨情仇一致性 / 情节是否太常规
- [ ] 未过项 → 重设计，不得动笔
### 轮次计划四件套模板（计划层强制）
> 根因补记（案例3）：C8 六轮计划未列"细纲"交付项——计划缺什么，执行就缺什么。轮次计划以四件套为单位命名，缺项=计划本身违规。

```
第N轮标准模板（四件套，缺一不可）:
  ① 细纲（本批5章·七项＋三栏表）——独立交付物，须落盘
  ② 正文 5 章
  ③ 四账本落盘 ＋ 章级快照
  ④ 检测点（逄5章）
```

## D. 创作期（每章）

- [ ] 章级配额：≥4 词签命中
- [ ] show+tell 双轨：B 大动作 + M 微表情 ≥各1处，显式签收尾
- [ ] 直陈情绪检查：无“我难过/很开心”类句式
- [ ] 梗频率：普通章≤1 处
- [ ] 章后速检：机械六项（英文/M2/明喻≤2/超限段/直引号/词签）

## E. 检测点（每 5 章）

- [ ] scan-emotion 全跑：总分记录
- [ ] 密度曲线判读：连续 2 点下滑且<4/千字 → 配额急救
- [ ] 签种涌现：连续 3 点零新签 → 题材词汇场预警
- [ ] 角色签进度：开卷 10 章内 ≥2 个显性场景；全书 7 角色签零空白

## F. 交付期（完结前）

- [ ] 总分 ≥25/39（上线线），冲刺 ≥29（真书均值），对标头部 38
- [ ] 机械六项全绿 + 全书完恰 ×1 + 桥接三禁复检
- [ ] 伏笔账全收 + 配角线闭合 ≥80%
- [ ] 全书钩子链复核（章标连读）
- [ ] 发布物料：简介（照 N 系列）、标签（对齐五层勾选）、标题查重

## G. 违例即停（红线）

```
上一阶未齐 → 不进下一阶
细纲未过诊断环 → 不动笔
创作未过章后速检 → 不入档
检测点报警未处理 → 不续写
红线全绿 = 稳定产出上榜资质
```

## H. 违规案例档案（反面教材·持续追加）

### 案例1 · 细纲断供事件（C1项目 ch4-14）
- **经过**：细纲只写到 ch3。ch4 起直接凭卷纲+设计卡心算写作，未产出书面七项细纲，未过诊断环。
- **代价**：①检测点2分值停滞（10/39，情绪目标项缺失致显式签漏配）②双轨带 5 次失守（本可预判）③英文漏网 1 次
- **兜底原因**：卷纲厚（章标含钩型）+设计卡全（六面体指纹）——侥幸，非流程。
- **修正铁律**：**卷纲再厚也不能替代细纲**。每章七项书面化，贴在设计卡目录下；写作前必须能指出"本章细纲文件路径"。章后归档时核对细纲→正文→速检三者一致。
- **判罚标准**：无书面细纲的章节，速检即便全绿也不计入"合格章节"——只算"素材"。
### 静场章例外条款（双轨带 12-25%）
- **定义**：情绪极点章（指纹兑现/生死离别/物抒情级），刻意压低对话
- **条件**（三条须同时满足）：①必须是情绪极点，不为省事 ②全书 ≤2 章 ③登记在案（书名+章号+理由+情绪目标）
- **登记簿**：C1《王爷只是个验尸的》ch19《娘的名册》——指纹兑现章（第三下落歪），双轨13%，2026-10 登记`n- **登记簿**：C1《王爷只是个验尸的》ch27《开棺》——开棺昭雪章，双轨14.6%，2026-10 登记（本书静场章已达2/2上限）
### 案例3 · 细纲断供+账本空转双重违规（C8项目全6轮）
- **经过**：双重违规——①细纲零产出（30章直接凭卷纲写作，无七项细纲）②四账本初始化后全程空转、零快照落盘。发布前双补录（细纲回填+账本回填）。
- **根因**：C8 六轮计划未列细纲交付项——计划层先违规，执行层照办。修正：轮次计划必须含四件套（见上）。
- **修正铁律**：心算=没做。每轮交付前必须实际落盘：①账本更新②章级快照③对账记录。详见 references/状态账本制与涌现剧场.md 第二节。
### 案例4 · 配额断供事件（C8项目·人当引擎模式）
- **经过**：SOP D阶段"章级配额≥4签"未在写作时执行，18分初稿写完才手工注入12处节拍补强（18→21）。
- **根因**：人当引擎模式下，引擎（助手）未把配额当写作约束，只当验收指标——顺序反了。
- **修正铁律**：配额是**写作前的约束**，不是写完后的补丁。人当引擎模式下每章落笔前必列本章4签；写完先跑检测器再交稿。修复手法本身已沉淀为"显式签补强pass"可复用规程（场景收尾处嵌入，禁直陈）。
### 案例5 · 字数断供（C9·30章仅9000字）
- **经过**：30章仅9000字（均300字/章），远低于网文2000-3000字/章标准
- **根因**：管线prompt写800字/章+人当引擎模式无字数意识
- **修正**：管线prompt提标2000-3000字+硬闸<1500重写；人当引擎模式每章底限2000字
- **铁律**：字数是体量，体量是上榜门槛——30章×2000字=6万字是最低可发布体量
### 案例5 · 偷工减料=产出低劣（C11项目·终极判例）
- **经过**：C11《剑葬九天》30章，设计卡+卷纲有了，但①细纲零产出（30章直接凭卷纲写作）②四账本初始化后全程空转③快照全是索引壳。终检仅11/39——**全系统最低分**。
- **根因**：不是能力问题，是**偷工减料**。跳过细纲省轮次、跳过账本省输出、跳过快照省时间——每一步"节省"都在削减最终质量。
- **因果链**：没写细纲→没签位配额→没情绪目标→显式签不嵌入→检测器分低。没记账本→没状态追踪→情绪弧断裂→角色不活→检测器分低。**两个偷懒叠加=11分**。
- **终极教训**：**偷工减料=产出低劣。这不是可能，是必然。** 任何跳过的步骤，最终都会以质量下降的形式偿还。C3(三世界乱炖19假)、C5(14但无账)、C6(19但账空)、C8(18但细纲缺)、C9(19但玄幻弱)、C10(15但字数缺)、**C11(11·偷工减料集大成)**——七本书的教训汇编如下：

| 偷了什么 | 后果 | 罚 |
|---|---|---|
| 细纲 | 签种不覆盖 | 分数低 |
| 账本 | 状态断裂 | 角色不活 |
| 快照 | 无法回溯 | 修改困难 |
| 显式签 | 检测器低 | 不可量化 |
| 连续性 | 三世界乱炖 | 读者迷惑 |
| 字数 | 体量不足 | 不上榜 |

- **终极铁律**：SOP 八项检查，一项都不能少。少一项，扣一项的分。这是数学，不是感觉。
