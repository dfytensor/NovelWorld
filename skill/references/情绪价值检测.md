# 情绪价值检测 · E系列（Emotional Value）
# 小说给读者的本质是情绪价值。角色标签（白月光/万人迷/团宠）= 情绪交付装置。
# 检测不到情绪标签的小说 ≈ 毫无情绪价值 ≈ 不会上榜。

---

## 一、三层词签体系（24 签）

| 层 | 词签 | 交付的情绪 |
|---|---|---|
| **情节**（事件型） | 打脸 / 逆袭 / 昭雪平反 / 认亲团圆 / 久别重逢 / 牺牲 / 身份反转 / 守护 | 爽·解气·期待·泪 |
| **角色**（人设型） | 白月光 / 万人迷 / 团宠 / 扫地僧 / 忠犬守护 / 外冷内热 / 病弱坚韧 | 心疼·向往·安全感·意难平 |
| **情绪**（体感型） | 爽 / 甜 / 虐哭 / 破防 / 燃 / 意难平 / 治愈温暖 / 扎心 / 悬念紧张 | 读者的直接体感 |

> 原理：读者推荐一本书时用的就是这些标签词（"哭死""意难平""男主是白月光"）。
> 词签=检测正则，见 `scripts/scan-emotion.ps1`（v2，24 签，千字密度阈值 0.5）。

## 二、使用

```powershell
.\scripts\scan-emotion.ps1 -Path <书目录或单文件>
# 输出: 每签命中数+千字密度 → "检出 N/24"
```

**判读基准**：
- 检出 ≤5/24：情绪价值稀薄，黄牌——优先补 情绪层+角色层
- 6-8/24：及格线，有交付但单薄
- ≥9/24：情绪价值充分
- 角色层 0 命中：货架吸引力弱——补 Y 系列颜值 + X 系列性格 + W 系列 CP 钩子

## 四、基线揭示的结构性结论

1. **强项=情节层+情绪层**：昭雪平反、守护、久别重逢、扎心、治愈——我们的书会"讲故事的眼泪"。
2. **弱项=角色层**：7 个未检出签里 4 个是角色签。白月光/万人迷/团宠这类**货架级角色钩子**全库缺失——这正是"有绝世美女的书更火"的市场实证：**读者先为人设点进来，再为情节留下来**。我们的书只有后者。
3. **处方**：新书选题时强制勾选 ≥2 个角色层标签（用 Y/X/W 系列落地），开卷 10 章内至少 1 次角色签的显性交付场景。

## 五、词签维护规则

- 单字词签禁用（"暖"在《暖气战争》误报 156 次→已修为"温暖|暖心|暖意"）
- 角色层词签是**短语签名**检测，近似而非充分——签未命中=读者难感知，签命中=可推荐语料
- 每新增一本书跑一次，基线表持续追加
- 平台热标签（番茄榜）每季度校准一次词签表
