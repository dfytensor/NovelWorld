# 表达体系大全 · T系列（Text Craft）
# 覆盖：战斗/修仙/宏大叙事/神秘/场景/环境/时间/对话节奏
# 每类含：标准模板＋高级变体＋禁用清单＋S/B/M 配合

---

## 一、战斗表达（W系列·War）

### 1.1 快战模板（一招定胜负）
```
公式：出招（一个动词）→ 效果（一个结果）→ 反应（一个微表情）
例："一剑。/ 剑光过处，铁甲裂成两半。/ 对面的人，瞳孔缩了一下。"
```
**禁用**：三段式描写（举剑→挥剑→命中），直接写结果。

### 1.2 恶战模板（拉锯战）
```
公式：攻防交替 ×3 → 转折点（受伤/破绽/援兵）→ 决胜一击
例：
第一回合："刀劈下来，他偏头。刀锋擦过耳廓，带走几根头发。"
第二回合："他反手一拳，打在对方肋上。对方闷哼一声，退了两步。"
第三回合："两人同时出手——拳头撞拳头，骨骼的声音比金属还脆。"
转折："然后他看到了——对方的左肩，有一个旧伤。"
决胜："一掌。按在旧伤上。"
```

### 1.3 群战模板（千军万马）
```
公式：远景（万军）→ 中景（一队）→ 近景（一人）→ 特写（一双眼）
例："十万大军压境。/ 先锋营五百铁骑，冲在最前面。/ 赵云单枪匹马，站在长坂坡上。/ 他的眼睛里，没有恐惧——只有一个字：守。"
```

### 1.4 战斗禁用清单
```
❌ "他感到一股强大的气息" → 用B系列替代（后背发麻/瞳孔缩了）
❌ "两人大战三百回合" → 写三个回合的具体动作
❌ "他的实力深不可测" → 用效果替代（一掌，城墙裂了）
❌ "两人打得难解难分" → 写一个占上风的细节（对方的刀，弯了）
```

## 二、修仙/玄幻表达（X系列·Xianxia）

### 2.1 境界突破模板
```
公式：积累暗示 → 临界点 → 突破瞬间（一短句）→ 效果（环境变化）
例："丹田里的灵气转了三十六个周天。第三十七个——卡住了。/ 他咬破舌尖。/ 破。/ 窗外的树，叶子全绿了。"
```
**关键**：突破瞬间不超过三个字。效果写在环境上。

### 2.2 法术对轰模板
```
公式：A出招（颜色+形态）→ B出招（颜色+形态）→ 碰撞（一个声音+一个效果）
例："左手火龙，右手冰凤。/ 对面：一道金色剑气。/ 三者在空中相撞——/ 轰。/ 方圆十丈，寸草不生。"
```

### 2.3 等级压制模板
```
公式：不写实力差距 → 写反应差距
例："金丹期来的时候，整个筑基期的修炼者——齐刷刷跪了。不是拜。是腿软。"
```

### 2.4 修仙禁用清单
```
❌ "他的修为深不可测" → 用效果（他路过，灵气自动让路）
❌ "强大的威压笼罩全场" → 用反应（所有人同时跪了）
❌ "一道惊天动地的法术" → 写结果（山，矮了三丈）
```

## 三、宏大叙事（E系列·Epic）

### 3.1 时代变迁模板
```
公式：大事件 → 小人物反应 → 一个物件的变化 → 时间跳转
例："王朝覆灭了。/ 街口的烧饼摊还在。只是烧饼从两文钱涨到了五文。/ 卖烧饼的老头换了一个——上一个，死在城破那天。"
```

### 3.2 战争叙事模板
```
公式：数字（伤亡）→ 一户人家 → 一个物件 → 无声
例："此役，死三万七千人。/ 城东的老李家，死了三个。/ 门口的灯笼，白布做的，挂了一年。/ 第二年，换成了红的。/ 再没人提。"
```

### 3.3 历史转折模板
```
公式：一个决定 → 一句话 → 后果（时间跳转）
例："皇帝说：'准了。'/ 就这两个字。/ 三百年后，历史学家还在争论——这两个字到底毁了一个王朝，还是救了一个王朝。"
```

### 3.4 宏大叙事禁用清单
```
❌ "历史翻开了新的一页" → 用具体物件变化
❌ "整个世界都变了" → 写一个不变的东西（烧饼摊还在）
❌ "无数人为之牺牲" → 写一个人（城东老李家死了三个）
```

## 四、神秘表达（M系列·Mystery）

### 4.1 伏笔暗示模板
```
公式：日常场景 + 一个不自然的细节 + 不解释
例："他打开门。桌上放着一张纸条。纸条上的字，是他的笔迹。可他没写过。"
```

### 4.2 氛围压迫模板
```
公式：正常环境 + 一个感官异常 + 沉默
例："巷子很安静。安静到——他能听见自己的心跳。可巷子里明明有风。有风就该有声音。"
```

### 4.3 恐怖暗示模板
```
公式：安全的环境 + 一个安全的东西 + 一个不安全的细节
例："房间里很整齐。床铺整洁，桌上放着水杯。可水杯里的水，是满的——这间房三年没人住了。"
```

### 4.4 神秘禁用清单
```
❌ "一股阴森的气息" → 用一个不自然的细节
❌ "他感到背后一阵发凉" → 用生理反应（后背发麻/汗毛竖起）
❌ "诡异的气氛笼罩着" → 写"不对劲的地方"（水杯是满的）
```

## 五、场景表达（S系列·Scene）

### 5.1 场景切换模板
```
公式：旧场景最后一个感官 → 新场景第一个感官
例（旧→新）：最后一个感官是"香味"→ 新场景开头是"臭味"
```

### 5.2 环境描写模板
```
公式：一个总体印象 + 三个感官细节 + 一个情绪暗示
例："这是一间破旧的屋子。/ 墙皮剥落，露出底下的红砖。/ 屋顶漏雨，地上摆了三个接水的盆。/ 空气里有霉味，和一种旧书特有的纸味。/ 这里的主人，不爱整洁——但爱书。"
```

### 5.3 时间流逝模板
```
公式：一个不变的东西 + 一个变化的东西 + 时间标注
例："老槐树还在。/ 但树下修鞋的人，从老张换成了小张。/ 三十年了。"
```

### 5.4 场景禁用清单
```
❌ "金色的阳光洒满大地" → 写具体的影子（影子从左墙移到了右墙——下午三点了）
❌ "美丽的风景令人心旷神怡" → 写一个具体效果（他忘了自己在赶路）
❌ "空气清新宜人" → 写一种气味（雨后的泥腥味，混着青草断茬的汁液味）
```

## 六、时间表达（T系列·Time）

### 6.1 时间跳转模板
```
公式：一个不变的东西 + 时间标注
例："老槐树还在。/ 但树下修鞋的人，从老张换成了小张。/ 三十年了。"
```

### 6.2 时间压缩模板
```
公式：三个快镜头 + "就这样"
例："春天播种，夏天浇水，秋天收割。/ 就这样，三年过去了。"
```

### 6.3 时间减速模板（关键场景拉慢）
```
公式：一个动作拆成五个步骤 + 每步一个细节
例："他拔剑。/ 手握上剑柄——冰凉的。/ 拇指推了推剑簧——咔。/ 剑刃出鞘一寸——寒光闪了闪。/ 然后他把剑推了回去。/ 不用拔了。对面已经跪了。"
```

## 七、对话节奏（D系列·Dialogue）

### 7.1 快节奏对话（吵架/紧张）
```
规则：不写"他说""她说"，直接交替对话
例："走。"
  "不走。"
  "你必须走。"
  "我不——"
  "走！"
```

### 7.2 慢节奏对话（谈判/告白）
```
规则：每句对话之间插一个动作/环境/心理
例："我喜欢你。"
  他看着窗外。风吹过树梢。
  "我知道。"
  她低着头，手指绞着衣角。
  "什么时候知道的。"
  "……很久了。"
```

### 7.3 沉默对话（不说话的对话）
```
规则：用动作代替对话——一个动作=一句话
例：她把伞递给他。
  他没接。
  她把伞塞进他怀里，转身走了。
  他站在雨里，手里拿着伞。
  伞是干的。
  他打开了伞。
```

## 八、全类别通用禁用清单

```
❌ "他心中一惊" → 用B系列（后背发麻/瞳孔缩了）
❌ "一股强大的气息" → 用效果（周围温度降了）
❌ "美得不可方物" → 写反应（所有人停止了说话）
❌ "他的眼神深邃如海" → 写具体（他看你的方式——像在称你的重量）
❌ "气氛十分尴尬" → 写一个尴尬的细节（有人咳了一声，没人接话）
❌ "时间仿佛静止了" → 写一个静止的细节（茶杯里的水纹，不动了）
```
