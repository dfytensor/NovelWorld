# 执行协议层 · 写作操作系统 v1.0

> 定位：把知识层的 112 个原子 + 30 个 EO 情绪原子 + 组合规则 + 约束，变成写作时的**自动执行动作**。
> 解决的问题：知识完备但执行时遗忘/遗漏/不知道该用什么。
> 使用方法：每章动笔前过一遍协议 → 写中按检查点走 → 写完跑自检。

## 三、写中检查点（每500字过一遍）

```
□ 500字检查点
  □ 当前段落是否至少用了1个原子？
  □ 当前段落有没有M2禁词（难过/害怕/想家）？
  □ 当前段落的对话比是否在25-40%？
  □ 读者读完这一段会不会想继续读？

□ 1000字检查点
  □ 是否到达或接近本章最高/最低情绪点？
  □ 感官通道是否至少调用了2种？
  □ 有没有至少1个"读者能感受到"的细节？

□ 章尾检查点
  □ 最后120字内有没有钩子？
  □ 钩子类型是否与上一章不同？
  □ 章尾是否在动作/对话/发现中悬停（而非总结）？
```

## 七、完整写作工作流（从零到完本）

```
阶段一：创建
  1. 需求访谈（8问） → 确定分类 → 查分榜基准线
  2. 构建 Layer A-E → 填五张设定卡
  3. 写样章 2 章 → 追更指数 ≥ 基准线 → 不达标重写
  4. 盲评 → 通过 → 进入生产

阶段二：生产（每章循环）
  1. 章前预检（5步检索协议）
  2. 写正文（按场景→原子匹配表 + 写中检查点）
  3. 写后自检（10项验证）
  4. 追更指数评分 → ≥基准线？→ 是：发布 / 否：重写
  5. 账本更新（事实/伏笔/状态回填）
  6. 下章预检准备

阶段三：卷间收口（每10章）
  1. 批次盲写协议（新批只读账本）
  2. 耐看爱看评分 → ≥70分？
  3. 文风指纹 diff → 偏差>20%重写
  4. 原子库更新 → 补充新原子
  5. 情绪剂量清点 → 下卷调整

阶段四：完本
  1. 全书耐看爱看终评 → S/A级？
  2. 全伏笔回收清单 → 全部✅？
  3. 平台适配 checklist → 全部✅？
  4. 投稿
```

## 八、涌现保证协议

```
涌现条件检验（每章写完后跑一遍）：

1. 多重性检验
   □ 本章用了几个原子？（≥3个 = ✅）
   □ 原子来自几个不同类别？（≥2个类别 = ✅）
   □ 有没有使用本章首次使用的原子？（有 = 多重性+1）

2. 相互作用检验
   □ 本章有没有至少1个原子组合？
   □ 组合是否产生了单个原子无法产生的效果？
   □ 组合效果是否可以命名？（如"柴=时间+思念+恐惧"）

3. 约束检验
   □ 本章追更指数 ≥ 分类基准线？
   □ 本章有没有触发一票否决？
   □ 剂量有没有超标？

如果以上全部 ✅ → 本章达到了涌现标准
如果任何一项 ❌ → 标记该段落，用缺失的原子重写
```

## 附：桥接章三禁（十书厂实测沉淀）

> 多卷本补写中段（桥接章）时的高频事故——桥接章越界抢戏。来源：P6 桥接章提前演完卷三结局＋魏全"自尽"违反卷三"活着守陵"核心设定；P10 桥接章引用了后卷才发生的"大论战"；P7 师延手稿"送了两次"。

### 三禁

1. **禁提前演重场戏**——后续卷章标里已存在的重场戏（封册大典/终极反转/主要角色死亡），桥接章一律不得预演。动笔前先读后卷章标清单，逐一对表。
2. **禁与后卷设定矛盾**——角色生死、立场、关系以**后卷正典为准**（后卷已完稿时）。桥接章的任何角色命运，写前先在后卷全文 grep 该角色名验证。
3. **禁提前引用后卷事件名**——后卷才发生的战役/典礼/运动等专有事件名，前卷桥接章不得出现（时间线未到）。用前卷已建立的事件替代（"二战之后"而非"大论战之后"）。

### 补写工序（桥接章专用）

```
Step 1: 读前卷尾章 + 后卷首页 —— 确定接口（从哪个状态接到哪个状态）
Step 2: 列后卷章标清单 —— 标出"不可碰"的重场戏与专有事件名
Step 3: 后卷 grep 关键角色 —— 确认生死/立场/关系现状
Step 4: 写桥接章 —— 只写"两卷之间必须发生的过渡"，重场戏留给正主
Step 5: 终检三查 —— 全书完计数（全书应恰 ×1）/ 专有事件名归位 / 角色命运无矛盾
```

### 附带检查：双"全书完"与卷标错位

- 每本书"（全书完）"必须**恰出现 1 次**且只在最后一卷
- 文件名卷标（卷一/卷二/卷三）必须与**章号区间一致**（ch26-35 属卷二就标卷二），以章号为准，不以内容自我声明为准
- 跨书角色名残留：多书厂共用角色名池（如江流/曹默/裴照），A 书的改名残留可能出现在 B 书——终检时对每个主角名做**全书厂 grep**，按书核对归属
