## 四、细纲提示词要素（模型格式合规的关键）

1. **few-shot 范例必须贴脸**（四行精确格式：兑现/新埋/角色变化/道具变化）——只说要求不给范例=格式必崩
2. **前情注入**：上一章末尾400字（连续性生命线）
3. **情绪配额**：正文≥4签，收尾处嵌入
4. **最具体匹配放最前**：提示词路由"七项细纲"须先于"卷纲"判断
5. 中文字符串内插值写 `$($_)章`（防变量名吞噬）

## 五、踩坑档案（全部真实踩过）

| 坑 | 解 |
|---|---|
| ps1 无 BOM 中文乱码 | UTF8Encoding($true)，三次中招 |
| 双轨硬闸在长跑中段停车 | E改记录模式；C改容忍——**起点可低，终点不松** |
| API 429 限流 | 重试退避 30×try；免费key扛不住量产——独立按量key或人当引擎 |
| LLM 输出细纲格式而非正文 | 提示词连"细纲"二字都不能出现＋few-shot 锁格式 |
| 高分假象（30梗概刷19分）| 连续性必须是独立闸——签分与叙事连贯正交 |
