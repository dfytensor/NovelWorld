# 情绪行为化表达 · B系列（Body-First）
# 真书库实证：高手写情绪从不写"我难过/我开心"——写身体，让读者自己推出情绪。
# 来源：F:\小说 头部书原文采样（超级兵王/斯文不败类等）

---

## 一、核心公式

```
情绪表达 = 生理反应(第一信号) → 动作代偿(第二信号) → 环境借位(第三信号)
禁用: "我难过""他很开心""她很紧张" —— 情绪名词一律禁止直陈
```

**三层示例（同一句"她很难过"）：**
- 生理层：`鼻尖一酸，差点哭出声`（真书原句）
- 动作层：`她转过身去，不让他看见`（真书原句式）
- 环境层：`满屋的安静，比哭还重`

## 二、生理反应词库（真书采样验证）

| 情绪 | 身体信号（禁直陈，只写信号） |
|---|---|
| 哭/悲 | 鼻子一酸 / 鼻尖一酸 / 眼眶一热 / 喉咙发紧发哽 / 眼泪刷地下来 |
| 怒 | 指节捏得发白 / 青筋 / 眯眼 / 声音很平（最怒时反而平静）|
| 怕/紧张 | 咽了口口水 / 手心沁汗 / 后背发麻 / 心提到嗓子眼 / 大气不敢出 |
| 心动/羞 | 耳根红了 / 心跳漏了一拍 / 别过脸去 / 假装看窗外 |
| 喜 | 嘴角上扬 / 脚步轻了 / 眉眼弯了 |
| 嘴硬手软 | 嘴上骂着，手却把碗推近了 / 说"不要"，接得比谁都快 |

## 三、进阶规则（人类化表达）

1. **反应先于认知**：身体先动，角色后知——"他发现自己攥紧了拳，才意识到在忍"
2. **动作错位**：越悲越做日常事（把骨头上的红绳紧一紧/把被角掖匀）——动作越平静，情绪越重
3. **转移物**：情绪落在道具上（荷包蛋/粗茶/披风/钥匙）——不写"想念"，写"把她的荷包蛋拨过去"
4. **沉默替代**：最重要的话不说——"他什么都没问"比千言重
5. **读者代偿**：写足信号，让读者自己说出那个情绪词——读者说出来的，才是他的情绪

## 四、与 skill 其他模块的接口

- **检测器兼容**：行为化表达后接一个显式词签收尾（show 三句 + tell 一句），质感与命中兼得
- **Y 系列**：颜值描写=外貌的行为化（不写美，写反应）；本篇=情绪的行为化——同源技术
- **X 系列**：性格六面体的"盾"，就是角色的习惯性生理反应（外冷内热者：喉结动一下，才说"嗯"）
