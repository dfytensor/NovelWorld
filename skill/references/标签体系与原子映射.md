## 三、情绪节奏模板（8种）

### 先虐后甜

```
节奏曲线：虐→虐→虐→虐→虐→虐→甜→甜→甜
比例：前70%虐，后30%甜
关键：甜的部分必须"赚回来"——虐有多深，甜就有多重
禁忌：不能中间突然甜（读者不信任）；不能甜的部分太短（读者觉得被骗）
释放节点：虐的顶点→一个小甜→再虐→再小甜→大甜
```

### 甜宠

```
节奏曲线：甜→甜→小虐→甜→甜→甜
比例：80%甜，20%小虐
关键：甜不能腻——要有新鲜感。每章的甜不能重复形式。
释放节点：日常甜→小意外→更甜→日常甜→告白→大甜
```

### 虐文

```
节奏曲线：虐→虐→虐→小甜→虐→虐→虐→更虐→结尾（可甜可虐）
比例：85%虐，15%微甜
关键：虐要有层次——每一段虐的方式不同。不能重复同一种虐法。
禁忌：为虐而虐=读者弃书。每一刀都要有理由。
```

### 爽文

```
节奏曲线：压→压→爽→压→压→爽→大爽→压→爽→大爽→终极大爽
比例：40%压，60%爽
关键：爽点不能重复形式——打脸、升级、获宝、救人、翻案，要轮着来。
禁忌：不能连续压太久（超过3章不爽=读者弃书）。
```

### 救赎

```
节奏曲线：堕→堕→触底→一线光→又堕→再一线光→挣扎→爬起→站直→走出
比例：前50%堕，后50%爬
关键：救赎不是别人给的。是自己走出来的。别人只能递灯。
禁忌：不能让救赎来得太容易。越难挣脱的黑暗，走出来越有力量。
```

### 惊悚

```
节奏曲线：安→疑→惧→安（假）→大惧→逃→安（真）
比例：30%安，40%惧，30%安
关键：惊悚的本质是"信息差"——读者知道危险但角色不知道，或反之。
禁忌：不能连续惊悚（读者会疲劳）。要安惧交替。
```

### 励志

```
节奏曲线：低→努力→小进步→挫折→再努力→大挫折→坚持→突破→成功
比例：30%低，50%挣扎，20%成功
关键：励志的本质是"变化"——从A到B的变化必须可见、可信、可感。
禁忌：成功不能来得太容易。也不能太难到不可能。
```

### 沙雕搞笑

```
节奏曲线：搞笑→搞笑→搞笑→突然温情→搞笑→搞笑→大搞笑
比例：70%搞笑，20%温情，10%其他
关键：搞笑的本质是"意外"+"共鸣"。意外让人笑，共鸣让人笑中带泪。
禁忌：不能为了搞笑而降低智商。角色可以犯蠢，但不能蠢得没有逻辑。
```

## 六、标签预期管理

> 标签是读者打开书之前与作者签的合同。
> 合同必须兑现。不兑现的合同=违约=弃书。

### 兑现原则

1. **主分类的承诺必须兑现**：主分类写了"悬疑惊悚"，就必须有悬疑和惊悚的要素。不能挂羊头卖狗肉。

2. **情节标签的承诺必须兑现**：打了"追妻火葬场"的标签，就必须有"追"的过程。不能跳过追逐直接原谅。

3. **情绪标签的承诺必须兑现**：打了"先虐后甜"的标签，就不能从头甜到尾。必须先虐。

4. **角色标签的承诺必须兑现**：打了"糙汉"的标签，角色就不能突然变成奶油小生。糙是底色，可以温柔，但不能不糙。

### 兑现度检查

```
□ 主分类的元素在第一章内出现？
□ 情节标签的核心冲突在前三章内触发？
□ 情绪标签的基调在前五章内确立？
□ 角色标签的人设在第一次出场时建立？
□ 所有标签的承诺在全书结尾前全部兑现？
```

### 映射到 skill 的路径

```
读者选标签 → 标签决定预期 → 预期决定结构 → 结构决定原子选择 → 原子决定执行

例：
读者选"悬疑惊悚+民间奇闻+救赎"
→ 预期：有悬疑要素+有灵异/奇闻+有救赎弧线
→ 结构：悬念→调查→发现→危机→解决
→ 原子选择：悬疑类原子（信息差/反转/伏笔）+ 奇闻类原子（独特设定/真实感）+ 救赎类原子（堕落→爬起）
→ 执行：写出来
```
