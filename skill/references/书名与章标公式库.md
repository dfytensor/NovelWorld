# 书名与章标公式库 · N系列（命名交付）
# 数据源：F:\小说 19万本真实书名采样 + 番茄排行榜 Top10 标题
# 原理：书名=第一广告位，章标=每章的门面。标签组合写作法在命名层的执行。

---

## 一、书名六式（真库采样验证）

| 式 | 公式 | 库样本 |
|---|---|---|
| 对白钩式 | 身份前缀 + 冒号 + 一句角色原话 | 绝色炼器师：王爷，不约！|
| 反差对撞式 | 冲突词 A + 要 + 冲突词 B | 丑妃要倾城 |
| 甜宠投喂式 | 属性词 + 太/好 + 可食用系词 | 鲜妻太可口：老公夜夜宠 / 新鲜小妻咬一口 |
| 读者代入式 | 群体词 + 该 + 如何 + 动词 | 炮灰女配该如何自救 / 我被迫时间回旋踢 |
| 双标签叠buff | 身份签 + 身份签 | 战神霸婿 / 至强兵医 |
| 独占宣言式 | 范围限定 + 情感动词 | 只许喜欢我 |

**番茄榜验证**：冷血暴君×幼崽太子（反差对撞）、疯癫公主靠抢劫建国（落差叙事）、笨蛋美人替嫁疯批王爷（角色签双排）。

## 二、章标四钩（上架/追更的门面）

| 钩型 | 公式 | 例 |
|---|---|---|
| 悬念式 | 未完成的动作/问题 | 谁在收 / 还不到日子 |
| 对白式 | 一句最锋利的台词当标题 | 账都在 / 今天风大 |
| 反差式 | 两不搭界的词并置 | 收破烂的爷爷（如果拆章：全县最懂账的收破烂的）|
| 数字/时间式 | 时间/数量制造期待 | 卷一终·三月十二 |

**番茄榜学习**：番外标题“当长大后的萧怀瑾穿越回父皇年幼时”——悬念+时空反差，追更钩力极强。

## 三、命名质检（三秒测试）

```
□ 念一遍：记得住吗？
□ 说不出三个卖点（标签）→ 重命名
□ 有没有“对白钩/反差/数字”至少一个？
□ 全书章标连读：钩型是否轮换（无同型连用）？
```

## 四、与创作五阶对接

- **阶段二（大纲）**：章标即在此产出——每标过“章标四钩”检验，钩型轮换记录在册
- **阶段一（设计）**：书名即标签组合的广告版——先定书名，反推标签勾选是否齐全（书名里数得出几个角色签/情节签？≥2 才合格）
