# 性格矩阵系统 · X系列原子
# 绝世美女要性格鲜明。所有角色要性格鲜明。性格要符合背景。
# skill 146 原子中零个系统教"性格设计"——X系列补这个盲区。

---

## 一、性格六面体

> 每个角色的性格 = 六个面的组合。六面不全 = 人物扁平。

| 面 | 含义 | 检验标准 |
|---|---|---|
| **表** | 别人看到的那一面 | 第一印象是什么？ |
| **里** | 独处时/面对信任的人时的那一面 | 亲近的人知道她什么秘密？ |
| **核** | 最深处的信念/恐惧/渴望 | 她半夜睡不着的时候在想什么？ |
| **盾** | 用来保护"核"的方式 | 她用什么方式不让别人看到"核"？ |
| **伤** | 造成当前性格的关键事件 | 什么经历让她变成现在这样？ |
| **变** | 在什么条件下性格会变/展现另一面 | 什么情况能让她打破"盾"？ |

**六面体检验法**：写完一个角色后，六面各写一句话。如果六句话有重复或矛盾→性格扁平或分裂。

## 二、美女性格十型

> 绝世美女+鲜明性格=读者记住十年。
> 绝世美女+没有性格=读者记住三页。

### 型1 · 外柔内刚
**表面**：温柔、好说话、从不拒绝别人
**内核**：比谁都倔。认定的事，十头牛拉不回来
**伤**：小时候被欺负过——学会用"柔"做盔甲
**盾**：温柔本身。没人防备一个温柔的人
**变**：触及底线时，温柔全消失，露出钢

**一句话**：她是绵里藏针。针是她的，绵也是她的。

### 型2 · 外冷内热
**表面**：不笑，不聊天，不合群，看起来高傲
**内核**：比谁都热心。谁有困难她都帮——但帮完就走，不留名
**伤**：热过一次，被伤过。从此学会冷
**盾**：冷漠。没人会去伤害一个冷漠的人
**变**：有人不怕她的冷、坚持接近她的时候——她会软化

**一句话**：她的冷不是拒人千里。是怕人靠近。

### 型3 · 外弱内韧
**表面**：瘦弱，多病，看起来一阵风就能吹倒
**内核**：比谁都韧。打不死，压不垮，踩进泥里也能开花
**伤**：从小体弱→被过度保护→反而锻炼了内心的韧性
**盾**：柔弱本身。没人防备一个看起来随时会倒的人
**变**：当她在乎的人受到威胁时——柔弱全消失

**一句话**：她不是不能坚强。她是不需要让你看见她的坚强。

### 型4 · 外喜内苦
**表面**：爱笑，爱闹，是全场的开心果
**内核**：苦到极点。笑是为了不让别人看到苦
**伤**：某个失去——从此学会用笑掩盖
**盾**：笑容本身。没人会去怀疑一个爱笑的人有苦
**变**：独处的时候、或喝醉的时候——笑容消失，露出底下的苦

**一句话**：她笑得最大声的时候——就是她最痛的时候。

### 型5 · 外艳内纯
**表面**：长得妖艳，穿着暴露，被认为不正经
**内核**：比谁都干净。内心纯净得像一张白纸
**伤**：因为长相被误解、被侮辱、被——但她从未因此改变自己
**盾**：不在乎别人怎么看。这个"不在乎"就是她的盾
**变**：当有人真正了解她、接受她的时候——她会展现出最柔软的一面

**一句话**：你们看到的是她的脸。我看到的是她的心。

### 型6 · 外强内裂
**表面**：最坚强、最能干、永远打不倒的那一个
**内核**：已经裂了。裂了很久了。只是没人看见
**伤**：常年扮演"坚强的那一个"→忘了自己也需要被照顾
**盾**：坚强本身。坚强的人不会被人问"你还好吗"
**变**：某一天——有一个人问她"你还好吗"→她会当场崩

**一句话**：她不是不需要被照顾。她是太久没被问了。

### 型7 · 外傻内明
**表面**：看起来傻乎乎的，被人当软柿子
**内核**：比谁都明白。什么都看得清，什么都不说
**伤**：曾经因为"太聪明"被排挤→学会装傻
**盾**：装傻。聪明人不会被人防备——但傻人有傻福
**变**：关键时刻——傻人说出最清醒的话

**一句话**：她不是傻。她是懒得跟你计较。

### 型8 · 外媚内正
**表面**：长得妖艳，穿着大胆，被认为不正经
**内核**：比谁都正直。有底线，有原则，有——脾气
**伤**：因为长相被误解、被侮辱——但她从未因此改变自己
**盾**：不在乎。这个"不在乎"是她的铠甲
**变**：当有人真正了解她、接受她——她会展现出最柔软的一面

**一句话**：你们看到的是她的脸。我看到的是她的心。

### 型9 · 外顺内逆
**表面**：顺从、听话、从不反抗
**内核**：比谁都有主见。顺从只是策略——她在等
**伤**：曾经反抗过→代价太大→学会等
**盾**：顺从。顺从的人不会被当目标
**变**：等到时机成熟的那一刻——顺从全消失

**一句话**：她不是不反抗。她是在等一个值得反抗的时刻。

### 型10 · 外普通内不凡
**表面**：长得普通，能力普通，扔进人堆里找不出来
**内核**：不普通。有一种别人没有的东西——可能是韧性、可能是天赋、可能是纯粹的善良
**伤**：因为"普通"被忽视→习惯了被忽视→不再期待被看见
**盾**：普通。普通是最好的保护色
**变**：当有人在人群中发现她、认出她的不普通→她会展现出完全不同的一面

**一句话**：她不是普通。她是还没被人发现的——不普通。

## 三、背景→性格推导规则

> 性格必须能从背景推导出来。推导不出来的性格=假的。

### 推导公式

```
背景事件 → 心理反应 → 应对方式 → 固化为习惯 → 成为性格
```

### 示例

| 背景事件 | 心理反应 | 应对方式 | 固化为性格 |
|---|---|---|---|
| 从小被欺负 | 不信任陌生人 | 用温柔做盔甲 | 外柔内刚 |
| 被最亲的人背叛 | 不再信任任何人 | 用冷漠做墙 | 外冷内热 |
| 常年生病被过度保护 | 内疚+想证明自己 | 逞强、逞能 | 外弱内韧 |
| 失去至亲 | 不敢面对 | 用笑掩盖 | 外喜内苦 |
| 因长相被误解 | 愤怒→习惯→不在乎 | 不在乎做铠甲 | 外艳内纯 |
| 常年被人依赖 | 疲惫但不好意思说 | 永远坚强 | 外强内裂 |

### 检验

写完角色的背景和性格后，问自己：

```
□ 如果我经历了这个角色的背景事件，我会变成这个性格吗？
□ 如果我变成这个性格，我的行为和这个角色一致吗？
□ 如果不一致——是背景写错了，还是性格写错了？
```

## 四、配角鲜明系统

> 不只是主角要鲜明。所有有名有姓的角色都要鲜明。

### 四要素法

每个配角必须有——

| 要素 | 含义 | 检验标准 |
|---|---|---|
| **独特说话方式** | 一开口就知道是谁 | 遮住名字，能猜出是谁说的吗？ |
| **独特小习惯** | 一个反复出现的小动作 | 读者能记住这个习惯吗？ |
| **独特矛盾点** | 表里不一的地方 | 这个矛盾让人意外吗？ |
| **独特与主角的关系** | 不是"朋友""敌人"这么简单 | 这个关系有第三层吗？ |

### 示例

| 配角 | 说话方式 | 小习惯 | 矛盾点 | 与主角关系 |
|---|---|---|---|---|
| 老福（管家） | 每句话都带"老奴" | 倒茶时杯底要对齐桌角 | 忠心但有时自作主张 | 从小看着主角长大 |
| 大姐头（白原） | 每句话最后加"嗯" | 说话时永远不看对方眼睛 | 最凶的人最护短 | 救过主角一命 |
| 阿菱（琴师） | 每句话都反问 | 弹琴时永远闭眼 | 嘴上说不帮，身体很诚实 | 唯一懂主角音乐的人 |

### 配角鲜明度检查

```
□ 遮住名字，能猜出是谁说的吗？
□ 这个角色有没有一个"读者能记住的小习惯"？
□ 这个角色有没有一个"意料之外情理之中"的矛盾？
□ 这个角色和主角的关系，有没有第三层？（不是简单的朋友/敌人）
□ 如果把这个角色删了，故事会不会缺一块？（会=必要角色，不会=可删）
```

## 五、性格一致性检查

### 一致性三条

1. **性格不能突变**——除非有重大事件触发，且要写出"变化的过程"
2. **性格在不同场景中可以展现不同面**——但核心不能变（外柔内刚的人，柔是日常，刚是底线）
3. **性格的"另一面"要在关键时刻展现**——平时藏着的，要在最重要的场景里爆发

### 一致性检查清单

```
□ 角色在第一章的性格和最后一章的性格，有变化吗？
□ 如果有——变化的原因是什么？变化的过程写了吗？
□ 如果没有——是刻意保持（角色弧线=不变），还是忘了写？
□ 角色在不同场景（战斗/日常/独处/面对不同人）中的表现一致吗？
□ 角色的"另一面"在关键时刻展现了吗？
□ 角色的行为，能用他的背景解释吗？
□ 角色的对话风格，从头到尾一致吗？
```
