# 梗与怼人体系 · G系列（幽默交付）
# 网络梗/搞笑段子/经典语录/怼人手段——情绪价值的高效催化剂
# 铁律：梗必须过"背景兼容闸"——古风文用当代梗=出戏，年代文用网络原梗=穿帮

---

## 一、幽默四法（搞笑段子骨架）

| 法 | 结构 | 例 |
|---|---|---|
| 反差 | 庄严场景+鸡毛蒜皮 | 大人物正怒，被一只鸡打断 |
| 夸张 | 把反应放大到荒谬 | "他震惊得手里的杯子都忘了掉" |
| 错位 | 用A的语域说B的事 | 用朝堂奏对口气讨论今天吃什么 |
| 自嘲 | 角色主动拆自己的台 | "我这个人，除了帅，一无是处" |

## 二、怼人五式（打脸签的执行手段）

| 式 | 结构 | 例 |
|---|---|---|
| 掀桌式 | 直接定性，不留余地 | "你这不是坏，是蠢得均匀。" |
| 借力式 | 拿对方的话反打 | "你说我不配？巧了，这话我也常对自己说——形容你。" |
| 阴阳式 | 表面客气，字字带刺 | "您真了不起，把简单的事办得这么复杂。" |
| 退进式 | 先认下再刺穿 | "是是是，都是我的错——错在太把你当回事。" |
| 降维式 | 用常识碾压 | "你跟我争的这事，卖菜的大妈都不争。" |

**使用规则**：怼人=打脸签交付手段；被怼方必须有反应（脸色变/说不出话）才算交付完成。

## 三、经典语录化用

- **改字嵌入**：把名句改一两个字嵌进对话（"十年生死两茫茫"→账本语境）
- **反向化用**：用反义输出金句（"人间不值得"→"人间值不值得，得自己记一笔账"）
- **禁用**：整句照搬+无改编（除非角色设定就是掉书袋）

## 四、网络梗转译表（背景兼容闸）

| 背景 | 用法 |
|---|---|
| 现代都市/职场 | 可原生使用（yyds/破防/emo），每章≤1处 |
| 年代(60-80s) | 必须转译：用当年的流行语（"杠杠的""的确良"式语感）表达同样的梗义 |
| 古代/古风 | 必须转译：梗义保留，外壳换成时代语（"震惊"→"唬得手里的茶盏都忘了搁"） |
| 玄幻/架空 | 自造体系内梗（"这灵根，比我家祠堂的柱子还直"）|

**频率控制**：普通章≤1处，重场戏≤2处。梗是盐不是饭——一碗饭放一把盐，整锅毁。

## 五、涌现用法

- 梗/怼人挂靠在【打脸/爽/破防】签上作为执行手段——先有签位（情节双闸过完），再上梗
- 章写岗配额：每 3 章至少 1 处怼人或搞笑交付（防全书过闷）
- 检测器顺带验证：怼人完成（对方被打脸）→ 打脸/爽签命中；段子成功（反差/错位）→ 破防/治愈签命中
