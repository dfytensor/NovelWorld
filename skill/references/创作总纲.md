# 创作总纲 · 标签组合创作法（Skill 主流程）
# 写小说 = 五层标签的组合 + 每个子标签对应的套路写法 + 情绪价值贯穿全程

---

## 一、创作流程（五步）

```
Step1 选题    勾 1 个主分类签（脑洞/悬疑/世情/权谋/年代/异能/玄幻因果）→ 创意涌现引擎产选题卡
Step2 配角色  勾 ≥2 个角色签（白月光/万人迷/团宠/扫地僧/忠犬/外冷内热/病弱坚韧）→ 全角色性格体系定人设
Step3 配情节  从 8 情节签选主线 2-3 条（打脸/逆袭/昭雪/团圆/重逢/牺牲/反转/守护）→ 剧情涌现引擎排卷纲
Step4 定情绪  定 1 主色 + 2 辅色（爽/甜/虐/燃/意难平/治愈/扎心/悬念）→ 配额制（见下）
Step5 定背景  勾 1 主背景（都市/古代/年代/小镇/校园/职场/宫廷/书稿世界）→ 搜索工序取材 + 背景检查清单
```

## 二、每层标签 → 套路/写法映射（skill 内部路由）

| 层 | 落地资源 |
|---|---|
| 主分类 | references/创意涌现引擎.md（选题卡+四层选择压）|
| 情节 | references/剧情涌现引擎.md + 标签体系与原子映射.md（34 情节标签→82 原子映射）|
| 角色 | 颜值描写体系(Y1-Y10+直给层) / 性格矩阵系统(六面体+X十型+全角色扩展) / 情感线体系(W1-W8) |
| 情绪 | 情绪操控智能.md(30 EO 原子) + 追更指数体系(钩型轮换/双轨带) |
| 背景 | 搜索工序手册(三件套) + 标签体系(10 背景检查清单) |

## 三、情绪价值贯穿线（全程五道岗）

1. **选题岗**：选题卡必须写明"本书交付哪 3 种读者情绪"（对应 Step4 主辅色）
2. **大纲岗**：每卷纲标注本卷情绪词签目标（如卷一=扎心+悬念，卷三=昭雪+燃）
3. **章写岗**：每章 ≥4 个情绪词签命中（轮换）；情绪层 9 签全书每签 ≥1 次交付
4. **角色岗**：7 角色签全书零空白；开卷 10 章内 ≥2 个角色签显性场景
5. **验收岗**：`scan-emotion.ps1` 检测 ≥25/39 上线，≥30 优良；对标真书库均值 29

> 核心认知（真书库实证）：情绪价值=词签轰炸密度。燃×1378 vs ×7 的差距就是上榜与扑街的差距。

## 四、全角色性格体系（X 系列扩展：不止美女）

X 十型原为美女性格设计，扩展为全角色通用——**每个主要角色都必须过一遍六面体（表/里/核/盾/伤/变）**：

| 角色位 | 推荐性格型（X 系列变体） | 套路要点 |
|---|---|---|
| 男主 | 外冷内热型 / 外傻内明型 / 外顺内逆型 | 冷面配 W8 闭嘴；装傻配身份反转 |
| 女主 | X 十型任选（外柔内刚/外弱内韧最稳）| Y 系列出场 + W 系列心动线 |
| 反派 | **外正内邪型**（体面人做恶事）/ 外狂内怯型（色厉内荏）| 反派也要六面体，恶要有逻辑，倒台要打脸签 |
| 长辈/师父 | 外严内慈型（嘴硬手软）/ 扫地僧型（深藏不露签）| 真相揭露=全书泪点引爆器 |
| 挚友/伙伴 | 外喜内苦型（开心果藏伤）/ 忠犬守护型 | 牺牲签的最佳载体 |
| 功能配角 | 配角四要素（说话方式/小习惯/矛盾点/三层关系）| 遮名可辨=合格 |

**通用铁律**：性格必须能从背景推导（背景→性格推导公式）；每型都要有"变"的触发条件写在人设卡上。

## 五、组合示例

```
主分类:年代纪实 + 角色:外冷内热(男主)+白月光(女二) + 情节:昭雪+守护
+ 情绪:主=意难平 辅=燃+扎心 + 背景:年代(60-80s)
→ 检测器验收目标 ≥28/39（年代词汇场天然高分，角色签补齐货架钩子）
```

## 六、情节双闸（搜索闸+反套路闸·强制·不可跳过）

> 事故复盘：《收破烂的爷爷》30章连载全程未用搜索工序、未跑反套路审查——凭原子库本能避开部分俗套属侥幸，不属流程。固化为硬闸：**每个情节设计（卷/章/场）未过双闸，不得动笔。**

### 闸1 · 搜索闸（落笔前必查）

```
查什么: F:\小说 同题材写法（grep 题材关键词，抽 2-3 本看同类场景处理）
        + find-atom.ps1 查库内已有原子（避免重复造轮）
查多深: 普通章≥2本对照；重场戏(卷首/卷尾/泪点/高潮)≥3本
产出:   同类文处理方式笔记 3-5 条（写进设计卡）
```

### 闸2 · 反套路闸（三栏对照表）

```
每个情节场景填三栏:
  栏1 俗套写法  = 我的第一反应（不许删，先写下来）
  栏2 同类文写法 = 搜索闸的产出
  栏3 我的写法   = 必须与栏1、栏2 都不同
栏3 撞车栏1或栏2 → 强制重设计，直到三栏互斥
```

### 执行时机（三层）

| 层级 | 双闸动作 |
|---|---|
| 卷纲设计 | 整卷情节逐条过双闸，产出卷级三栏表 |
| 章前 | 该章场景清单过闸（栏1→栏2→栏3 各一行）|
| 重场戏 | 加倍：搜索≥3本，栏1 必须写出"为什么这是俗套" |

### 违例即停

未附三栏表的章节，不得进入写作环节；机械检查环节发现无三栏表 → 退回重过闸。
双闸产出随设计卡归档（账本化），供后续反查"哪些套路已用过"。

## 七、创作五阶（正式管线·本节为最高规程）

```
设计 → 大纲 → 细纲(持续诊断) → 创作 → 润色(变艺术)
```

### 阶段一 · 设计
产出：
1. 五层标签勾选：主分类/情节/角色/情绪/背景（含题材定调）
2. 人物卡：主角+全部配角——X 六面体(表里核盾伤变)+Y 颜值(含直给层)+性格指纹(微表情习惯)
3. 世界观：背景检查清单过一遍；力量/规则/货币等体系（如需要）
4. 选题卡：写明本书交付哪 3 种读者情绪（对应检测器签位）

### 阶段二 · 大纲
产出：
1. 主要发展节点：每卷 3-5 个大节点（起承转合明确）
2. 章节标题：**必须带钩子**（悬念/反差/疑问式），全书钩型轮换禁同型连用
3. 时间节点：每卷一句"时间账"概括（DXX：发生什么）

### 阶段三 · 细纲（最重·持续诊断节）
每章列七项：
1. 伏笔：本章埋什么/收什么（埋收配平）
2. 出场人物：谁出场，关系是否有推进
3. 钩子：章尾钩（型别标注）
4. 一句话概述：本章干什么
5. 段子/梗：用什么梗（过背景兼容闸）、怼人交付点
6. 情绪起伏：本章词签目标（≥4 签，与卷情绪主色对齐）
7. 情节三栏表：俗套/同类文/我的——过双闸（搜索闸+反套路闸）

**持续诊断环（每写新章细纲前重跑全篇）**：
- 钩子链：无同型连用、无断链
- 伏笔账：埋收配平、无遗忘
- 人物账：爱恨情仇不突变、动机可溯（背景推导）
- 反套路：情节**不能太符合常规**——过于顺拐即重设计

### 阶段四 · 创作
- 章级配额：≥4 词签命中
- show+tell 双轨：B 大动作+M 微表情 三句 + 显式签一句
- 章后速检：机械六项+词签扫描

### 阶段五 · 润色（变为艺术）
- 检测器全跑+对标（≥25/39 上线，对标真书均值 29）
- 行为化替代直陈：无 B/M 系列直陈情绪的段落重写
- 梗频率复查（普通章≤1）、俗语污染清理
- 长跑验证协议：每 5 章检测点，密度曲线判读

> 五阶铁律：上一阶产出未齐，不得进下一阶；细纲未过持续诊断环，不得动笔；创作未过章后速检，不得归档。
