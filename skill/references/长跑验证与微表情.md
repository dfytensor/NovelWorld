## 一、长跑验证协议（连载必执行）

### 检测点制度
- 每 5 章 = 1 检测点：跑 scan-emotion.ps1 + 机械六项
- 记录三个数：签种数/39、总命中数、正文千字数

### 密度曲线判读
- 分段密度 = 区段命中数 ÷ 区段千字数
- **正常形态**：开篇高 → 建卷期回落(4-5/千字正常，设定让位结构) → 剧情线爆发期回升(6-8/千字)
- **衰减警报**：连续 2 个检测点密度下滑且 <4/千字 → 触发词签配额急救（总纲第三岗）
- **签种涌现指标**：后期仍出现新签种 = 涌现健康；连续 3 检测点零新签 = 题材词汇场枯竭预警

### 实测基线（收破烂的爷爷·30章）
```
8.8 → 4.4 → 5.0 → 7.5 → 6.4 （V型回升，无衰减）
签种 16→16→18→20 持续新增 | 机械 30 章零漂移
```
未验证边界：30 万字尺度（真书标准）——曲线每 5 章自动延长。

## 二、微表情体系（M系列·B系列的精细层）

> 真书库采样（斯文不败类等头部书）：情绪不止写在身体大动作上，更写在脸上 0.5 秒的失控。

### 词库（真书原句验证）
| 情绪 | 微表情 |
|---|---|
| 嘲讽/不屑 | 嘴角勾起一抹嘲讽 / 勾起不屑的弧度 |
| 真笑vs假笑 | 笑意很浅，但那弧度是真心实意的（弧度辨真伪）|
| 隐藏情绪 | 眼神一暗，极快地敛了 / 瞳孔一缩 |
| 心虚/动摇 | 眉头一皱又松开 / 睫毛轻颤 |
| 忍怒 | 下颌绷紧 / 喉结滚动一下 |
| 慌乱掩静 | 指尖微顿，随即如常 |

### 三层配合公式（与 B 系列合龙）
```
大动作(B系列)：拍背/掖被角/拨荷包蛋 —— 承载情绪的量
微表情(M系列)：眼神一暗/喉结滚动 —— 泄露情绪的真
显式词签(tell)：守了十年/心提到嗓子眼 —— 交付情绪的钩
```
**规则：一个场景三层各至少一次；微表情负责"说漏嘴"——角色藏得住动作，藏不住 0.5 秒的脸。**

### 与 X 系列接口
性格六面体的"盾"决定微表情的暴露方式：外冷内热者=喉结动一下才说"嗯"；外傻内明者=笑容慢半拍——**微表情是性格的指纹，同一情绪不同角色脸上长得不一样。**
